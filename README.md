# Trabalho DevOps 2 – Relatório das Atividades Práticas de Fundamentos de DevOps

Relatório técnico da Unidade Curricular **Fundamentos de DevOps** (UNISENAC Pelotas), cobrindo as
práticas com **Vagrant, Git e GitHub, Ansible, Docker, SonarQube e Jenkins** e a integração entre elas.

## Conteúdo do repositório

| Caminho | Descrição |
|---|---|
| `Aula *.pdf` | Material das aulas usado como base do relatório |
| `relatorio/` | Projeto LaTeX para o Overleaf (arquivo principal: `main.tex`) |
| `relatorio/codigos/` | Arquivos do laboratório: Vagrantfiles, scripts de provisionamento, projeto Ansible, Dockerfiles, SonarQube e Jenkinsfiles |
| `relatorio/LEIA-ME.md` | Como subir no Overleaf, lista dos 34 prints e o que conferir antes da entrega |
| `relatorio-preview.pdf` | Prévia compilada do relatório (ainda com as caixas indicando onde entram os prints) |

## Próximos passos

1. Tirar os prints listados em `relatorio/LEIA-ME.md` e salvá-los em `relatorio/prints/`.
2. Preencher os campos destacados em amarelo (`[PREENCHER: ...]`) e revisar os trechos marcados com `% CONFIRA`.
3. Reescrever a pergunta reflexiva final com as próprias palavras.
4. Subir a pasta `relatorio/` no Overleaf, recompilar e entregar no Blackboard.
